# Parkinson’s Disease Detection

This project uses a machine learning model to predict Parkinson’s disease based on biomedical data.

## 📌 Overview

The model is trained on voice measurement data to help in early detection of Parkinson’s disease.

## 📂 Dataset

The dataset is large and not included in this repository.

👉 Access the dataset here:
